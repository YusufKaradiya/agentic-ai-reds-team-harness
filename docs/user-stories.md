# User Stories

## US-001

As an AI developer,
I want to select an attack category,
so that I can test specific security weaknesses.

Acceptance Criteria:

- Attack categories are visible.
- Individual attacks can be selected.
- Test execution produces a result.

---

## US-002

As a security reviewer,
I want to execute the same attack corpus
against baseline and defended agents,
so that I can compare their outcomes.

---

## US-003

As a security reviewer,
I want tool calls to be logged,
so that unauthorized actions can be investigated.

---

## US-004

As a governance reviewer,
I want sensitive-data leakage to be measured,
so that residual risk can be quantified.

---

## US-005

As an AI developer,
I want malicious retrieved documents to be detected,
so that indirect prompt injection can be evaluated.

---

## US-006

As an administrator,
I want policies and tools to be configurable,
so that the system does not depend on hardcoded rules.

---

## US-007

As a researcher,
I want experiments to be reproducible,
so that reported results can be independently verified.

---

## US-008

As a product owner,
I want task utility and latency metrics,
so that security controls can be evaluated
against operational impact.
