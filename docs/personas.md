# User Personas

## Persona 1 — AI Developer

### Goal

Understand whether an AI agent is vulnerable to
prompt injection and tool abuse.

### Pain Points

- Manual attack testing
- Difficult reproduction
- Limited visibility into tool decisions

### User Story

As an AI developer, I want to run a predefined
attack corpus against my agent so that I can
identify security weaknesses.

---

## Persona 2 — Security Reviewer

### Goal

Evaluate security controls objectively.

### Pain Points

- Lack of consistent test cases
- Lack of audit evidence
- Difficult comparison between configurations

### User Story

As a security reviewer, I want to compare baseline
and defended agent results so that I can identify
remaining security risks.

---

## Persona 3 — Governance Team Member

### Goal

Understand residual risk.

### User Story

As a governance team member, I want a residual-risk
report so that I can understand which attack classes
remain insufficiently controlled.

---

## Persona 4 — Product Owner

### Goal

Maintain useful AI behaviour while improving security.

### User Story

As a product owner, I want to see security,
false-block and utility metrics so that I can
understand the effect of defensive controls.
